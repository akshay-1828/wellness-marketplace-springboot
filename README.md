# 🌿 Wellness Marketplace for Alternative Therapies

A full-stack wellness marketplace that connects users with alternative therapy practitioners and provides features such as therapy session booking, practitioner verification, wellness product shopping, AI-powered recommendations, community discussions, and session reminders.

## 🚀 Features

### 👤 User Management
- User registration and login
- JWT-based authentication
- Google OAuth authentication
- Password reset functionality
- Role-based access

### 🧘 Therapy & Practitioner
- Browse practitioners
- Practitioner profiles
- Practitioner onboarding
- NPI-based practitioner verification
- Availability and time-slot management
- Therapy session booking
- Session management

### 🛒 Wellness Marketplace
- Browse wellness products
- Product details
- Shopping cart
- Wishlist
- Product reviews
- Order management
- Payment workflow

### 🤖 AI & Recommendations
- AI-powered wellness recommendations
- AI chatbot
- Personalized recommendations
- Groq API integration

### 💬 Community
- Community questions and answers
- Reviews and discussions

### 📧 Notifications
- Email Reset Password Service 
- Session reminders
- Scheduled reminder service

### 📅 Integrations
- Google Calendar integration
- NPI Registry API
- OpenFDA API
- WHO API
